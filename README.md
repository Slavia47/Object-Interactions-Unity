# Object interactions Unity repo
Code for unity version 6000

Dependencies:
  -Requires RB on the object to be moved around.
  -must use input actions controler
Usage Guide:
  -Remember to assign player camera in the inspector to the object for holding function.
  -Using input actions editor from unity requires set up of push, pull and hold. Either take from this player input or add to your own. Warning it may overide if you have already modified the input controler.
